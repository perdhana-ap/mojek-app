## 📱 Tentang Project

MOJEK adalah aplikasi layanan pesan antar makanan yang terdiri dari beberapa aplikasi dalam satu platform.

- 👤 Customer
- 🛵 Driver
- 🏪 Merchant
- 🛠 Admin


# 🌳 Git Workflow

Semua fitur dikembangkan menggunakan branch.

Contoh:

```
main

feature/login

feature/customer-home

feature/merchant

feature/driver

feature/payment

feature/maps
```

Tidak melakukan development langsung pada branch `main`.
